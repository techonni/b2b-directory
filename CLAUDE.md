# zunrel

Site zunrel.com: jogos HTML5 demo (Crash, Binary), feito **só com PixiJS v8 + GSAP + TypeScript + Howler.js**. Não adicionar outras bibliotecas nem UI em HTML/CSS — tudo é desenhado no canvas.

- Tema: tokens em `src/core/theme.ts` (UI Design Rules – HTML5 Games). Textos da UI em português.
- Novo jogo: criar `src/games/<nome>/` com uma classe que implementa `GameScene` e registá-lo em `src/main.ts` e `src/site/Header.ts`.
- Verificar sempre com `npm run build` (inclui o typecheck).
- Créditos fictícios apenas: nada de dinheiro real, depósitos ou levantamentos.
