# Prompts curtos para o Claude no Chrome

O prompt grande (`../PROMPT-COWORK-CHROME.md`) encravou o Claude do Chrome a 28/09. Use estes em vez dele.

**Como usar**
1. Uma conversa nova do Claude no Chrome **por prompt** (fecha a anterior).
2. Copia o texto do ficheiro e cola.
3. Quando ele responder, **copia a resposta e cola-a ao Claude Code** (sem GitHub: é mais leve e não encrava).
4. Nunca ao mesmo tempo que o Claude Code está a trabalhar.
5. Se ele encravar mais de 5 minutos: fecha, abre uma conversa nova e cola o mesmo prompt.
