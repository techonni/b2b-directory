# Fontes

Põe aqui `Sora.ttf` e `JetBrainsMono.ttf` (fontes variáveis, Google Fonts, licença OFL):

- https://fonts.google.com/specimen/Sora → Download → `Sora-VariableFont_wght.ttf` → renomear para `Sora.ttf`
- https://fonts.google.com/specimen/JetBrains+Mono → Download → `JetBrainsMono-VariableFont_wght.ttf` → renomear para `JetBrainsMono.ttf`

Sem elas a app funciona na mesma, com a fonte do sistema (San Francisco).
