# Rotina diária do Claude no Chrome (Co-work)

Pedida pelo Techonni a 28/09/2026. Três trabalhos por dia, **cada um numa conversa separada** (máximo 3 tarefas e 2 sites de cada vez, para não encravar).

## Antes de começar (obrigatório)

1. Ler o topo de `docs/growth/RESULTADOS-CHROME.md` para saber o último « Dia N » feito.
2. **Avisar o Techonni e esperar o « sim »:** « Hoje vou fazer: A) publicação X + LinkedIn (dia N), B) verificação Impact + PartnerStack, C) 5 pins Pinterest (dia N). Posso começar? » Nada começa sem resposta. Se ele disser só uma letra, fazer só essa.
3. Nunca ao mesmo tempo que o Claude Code está a trabalhar.

## A · X e LinkedIn (sites: x.com, linkedin.com)

1. Publicar no LinkedIn o texto do « Dia N » de `docs/growth/fila-redes.md` (link com `utm_source=linkedin`).
2. Publicar no X a versão curta do mesmo dia (link com `utm_source=x`).
3. Anotar em RESULTADOS-CHROME.md: « Diário · data · A feito (dia N) » com os links das 2 publicações.

## B · Impact e PartnerStack (sites: impact.com, partnerstack.com)

1. **Verificar:** perfil completo e atualizado (site zunrel.com, descrição, métodos de promoção, dados de pagamento sem erros), avisos ou erros na conta, e cliques, conversões e comissões dos últimos 7 dias.
2. **Procurar:** programas ou links de afiliação novos dos parceiros atuais (Shopify, Leadpages, HTML Pub). Copiar os links, não os pôr no site (isso é trabalho do Claude Code).
3. **Mensagens:** listar as mensagens recebidas sem resposta e escrever uma resposta profissional (em francês ou inglês, conforme a mensagem). **Mostrar cada resposta ao Techonni e só enviar com o « oui » dele.** O mesmo para qualquer mudança no perfil: propor, esperar o « oui », depois guardar.

Anotar em RESULTADOS-CHROME.md: números, links novos, erros encontrados, mensagens respondidas (sem dados pessoais nem dados bancários).

## C · Pinterest (site: pinterest.com)

1. Publicar os 5 pins do « Dia N » de `docs/growth/fila-redes.md`: imagem, título, descrição, painel e link com UTM, exatamente como na tabela.
2. Não criar guias nem imagens novas.
3. Anotar em RESULTADOS-CHROME.md: « Diário · data · C feito (dia N) ».

## Regras de sempre

- Não comprar, não mudar planos, não apagar, não aceitar autorizações sem o Techonni.
- Nunca inventar números nem links de afiliação.
- Se encravar mais de 5 minutos: parar, dizer ao Techonni, recomeçar numa conversa nova.
- Se a fila acabar (não houver « Dia N »), dizer: « A fila acabou. Diz "continua" ao Claude Code. »
